# CSS Week 2 Homework

This project contains three HTML pages using one shared CSS stylesheet.

## Files
- `index.html` — home page
- `neighborhood.html` — neighborhood page
- `parks.html` — parks page
- `css/style.css` — shared styles for all pages

## Publish with GitHub Pages
1. Extract this ZIP file.
2. Upload all files and the `css` folder to the root of your GitHub repository.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The live URL will appear in the Pages section.

## Accessibility check
After publishing, test each page with https://wave.webaim.org/ and fix any issues reported.
